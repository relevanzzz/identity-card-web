# wering.la

Meine persönliche Website – eine kleine Visitenkarte mit Infos über mich und einem Kontaktformular.

## Was ist drin?

- `index.html` – die Seite selbst
- `style.css` – das Design (Farbverlauf über einem Foto von Landshut, auf dem Handy untereinander)
- `script.js` – prüft das Kontaktformular und öffnet dann das Mailprogramm
- `images/` – Bilder

## Benutzt

- HTML, CSS und JavaScript (ohne Framework)
- [Font Awesome 4.7](https://fontawesome.com/v4/) für die Icons
- [Poppins](https://fonts.google.com/specimen/Poppins) von Google Fonts
- GitHub Pages zum Hosten

## Lokal anschauen

Einfach `index.html` im Browser öffnen.
